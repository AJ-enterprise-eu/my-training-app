# My Training

Simple installable fitness tracker focused only on workouts.

## Features
- 5-day split
- Set-by-set tracking
- Rest timer with pause / +15 sec / skip
- Machine / station memory
- Notes for each exercise
- History, PRs, and volume
- Works on mobile and can be added to Home Screen

## Publish on GitHub Pages
1. Upload all 6 files to the root of your `my-training-app` repository.
2. On GitHub: **Settings → Pages**
3. Under **Build and deployment**, choose:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
4. Save.
5. Wait 1–3 minutes.
6. Your app will be live at:
   `https://AJ-enterprise-eu.github.io/my-training-app/`

## Install on iPhone
Open the Pages link in Safari → Share → Add to Home Screen.
