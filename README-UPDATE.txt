# My Training Coach v3 — update package

Upload these 4 files to the root of the existing `my-training-app` repository and replace the old files when prompted:

- index.html
- coach-v3.js
- service-worker.js
- manifest.json

GitHub Pages will redeploy automatically.

If the old version still appears on iPhone:
1. Open the Pages site in Safari.
2. Reload once.
3. If installed to Home Screen, close the app completely and reopen it.
